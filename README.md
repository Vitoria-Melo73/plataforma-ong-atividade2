# 🌐 Plataforma ONG - Conectando Voluntários

Este repositório contém o desenvolvimento de uma plataforma web voltada para o terceiro setor, facilitando a interação entre voluntários e causas sociais. O projeto foca-se em usabilidade, design limpo e acessibilidade.

## 📝 Funcionalidades
* **Página Inicial (Landing Page):** Apresentação da missão e valores da organização.
* **Sistema de Login/Cadastro:** Interface para autenticação de utilizadores.
* **Secção Institucional:** Espaço dedicado à história e ao propósito da ONG ("Quem Somos").
* **Navegação Intuitiva:** Menu responsivo para facilitar o acesso às diferentes áreas do site.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de todas as páginas.
* **CSS3:** Estilização moderna, utilização de Google Fonts e layouts responsivos.
* **Conceitos de UI/UX:** Foco numa interface amigável e de fácil navegação para todos os públicos.

## 🚀 Como Visualizar
Atualmente, o projeto é composto por ficheiros estáticos. Para visualizar, basta abrir o ficheiro `index.html` em qualquer navegador web.
